Media Query nima?

Media Query — CSS ning bir xususiyati bo'lib, u ekran o'lchamiga yoki qurilma turiga qarab turli uslublar qo'llash imkonini beradi.

Sodda qilib aytganda: "Agar ekran kengligi 600px dan kichik bo'lsa, ushbu CSS qoidalarini ishlatish" degan mantiqiy shart.

Asosiy sintaksis:

@media (shart) {
  /* shart bajarilganda ishlaydigan qoidalar */
}

/* Misol: 600px dan kichik ekranlar uchun */
@media (max-width: 600px) {
  body {
    background: lightblue;
    font-size: 14px;
  }
  h1 {
    font-size: 24px;
  }
}

Media Query turlari

1. max-width — eng ko'p ishlatiladigan

/* 768px dan kichik ekranlar uchun */
@media (max-width: 768px) {
  .container { flex-direction: column; }
}

2. min-width — Mobile First usuli

/* 768px dan katta ekranlar uchun */
@media (min-width: 768px) {
  .container { flex-direction: row; }
}

3. oraliq (range) — planshetlar uchun

/* Faqat planshetlar uchun: 768px dan 1024px gacha */
@media (min-width: 768px) and (max-width: 1024px) {
  .sidebar { width: 240px; }
}

4. orientation — qurilma holati

/* Gorizontal holat */
@media (orientation: landscape) {
  .hero { height: 100vh; }
}
/* Vertikal holat */
@media (orientation: portrait) {
  .hero { height: 50vh; }
}

Mobile First vs Desktop First

Mobile First (tavsiya etiladi) 
/* 1. Avval telefon uchun */
.container {
  flex-direction: column;
  padding: 12px;
}
/* 2. Planshet uchun */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}
/* 3. Kompyuter uchun */
@media (min-width: 1024px) {
  .container {
    max-width: 1200px;
  }
}
Desktop First (eski usul) 
/* 1. Avval kompyuter uchun */
.container {
  flex-direction: row;
  max-width: 1200px;
}
/* 2. Planshet uchun */
@media (max-width: 1024px) {
  .container {
    flex-direction: column;
  }
}
/* 3. Telefon uchun */
@media (max-width: 768px) {
  .container {
    padding: 10px;
  }
}
Tavsiya: Mobile First usulidan foydalaning — internet trafigining 60%+ dan ko'pi mobil qurilmalardan keladi. Avval kichik ekranni optimallang.

Xulosa — asosiy fikrlar

  • @media — CSS ning saytni qurilmalarga moslashtiruvchi xususiyati
  • max-width — shu kenglikdan kichik ekranlarga qoidalar qo'llaydi (Desktop First)
  • min-width — shu kenglikdan katta ekranlarga qoidalar qo'llaydi (Mobile First)
  • Mobile First tavsiya etiladi — avval telefon, keyin kattaroq ekranlar
  • Breakpoints: 480px · 768px · 1024px · 1200px — standart qiymatlar
  • orientation — qurilmaning landscape yoki portrait holatini aniqlaydi
  • and — bir nechta shartni birlashtiradi: and (max-width: 1024px)
