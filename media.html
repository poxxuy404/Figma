Media Query nima?

Media Query — veb-saytni turli qurilmalarga (telefon, planshet, kompyuter) moslashtirish imkonini beradi.

Sodda qilib: "Agar ekran kengligi 600px dan kichik bo'lsa, ushbu uslublarni qo'lla" degan shart. 
@media (max-width: 600px) {
    body {
        background: #f0f0f0;
    }
    h1 {
        font-size: 24px;
    }
}
Amaliy ko'rinish quyidagi oynani kichraytiring

Breakpoints (qurilma o'lchamlari)

Qurilma Kenglik Media Query
Telefon 0 - 600px @media (max-width: 600px)
Planshet 601 - 1024px @media (min-width: 601px) and (max-width: 1024px)
Kompyuter 1025px+ @media (min-width: 1025px)

Mobile First (tavsiya etiladi)

/* Avval telefon uslubi */
.container { flex-direction: column; }
/* Keyin planshet */
@media (min-width: 768px) {
    .container { flex-direction: row; }
}
/* Keyin kompyuter */
@media (min-width: 1024px) {
    .container { max-width: 1200px; }
}

Xulosa

  • @media — saytni turli qurilmalarga moslashtirish
  • max-width — berilgan kenglikdan kichik ekranlar uchun
  • min-width — berilgan kenglikdan katta ekranlar uchun
  • Mobile First — avval telefon, keyin kattaroq ekranlar
  • Breakpoints: 600px (telefon), 768px (planshet), 1024px (kompyuter)
Amaliy maslahat: Chrome DevTools (F12) da turli qurilmalarni tanlab sinab ko'ring!
